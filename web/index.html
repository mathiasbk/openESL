Open firmware for e-paper shelf labels

Turn SoluM e-paper tags into labels you control. An ESP32 access point sends them your text over radio, and any software can talk to it over plain HTTP.

Flash the firmware Try the demo Read the wiki GitHub

  1. Flash the APAn ESP32 board over USB, in the browser.
  2. Flash the tagsOne by one in a jig, with a D1 mini flasher.
  3. Send contentFrom the HTTP API, Home Assistant or a CSV file.

        This is a layout file

        A layout file holds the designs (layouts) the AP draws one tag model's screens with. It starts with a few examples to try or change.

        1. Draw a layout: pick one in the list of layouts, or add one, and place text fields, boxes and codes on the tag.
        2. Send it to your AP with Send to your AP… at the top. The AP keeps the file; the tags need nothing new.
        3. Send content from Home Assistant, esl-client or your own software: the layout's name and a text for each field. Use next to a layout shows how.
        The AP's limits for this layout

        Built-in layouts are part of the firmware and cannot be edited. Pick a layout from the file, or make a new one, to design your own. You can still try the sample text and send it.

        Keys and tips
        • Drag a box to move it, drag its edge or corner to resize. It snaps to the screen's edges and centre and to the other boxes; hold Alt to place it freely.
        • ← → ↑ ↓ move the selected box 1 px (Shift: 10 px). Tab picks the next box, Esc deselects, Delete removes it, Ctrl+D duplicates it, Ctrl+C and Ctrl+V copy it to another layout.
        • Ctrl+Z undoes, Ctrl+Shift+Z redoes.
        • Drag an element in the list to draw it further forward or back.
        • For white text on black, give the text the colour Inverted, or put white text on a black box.
        • The preview is the tag's own pixels, drawn and checked by the AP's code, so what you see is what the tag shows.

        Send to your AP

        How is your AP connected?

        Pick the AP's port in the list the browser shows. Close anything else that uses it first, such as esl_client.py ... serve.

        This browser cannot use USB ports. Use Chrome or Edge on a computer, or choose WiFi.

        Your AP's own page opens in a new tab with this layout file. Check it there and press Save. Nothing to install.

        The AP needs firmware 0.9.0 or newer for this (the Dashboard tab shows its version and updates it). With older firmware, use the USB cable, or the bridge under Advanced.

        Advanced: through the esl-client bridge (older AP firmware, or to pick a tag and check it from here)

        Start the bridge in tools/esl-client on this computer: python3 tools/esl-client/esl_client.py --url http://<AP's address> --token <token> serve, then connect to http://localhost:8080. A page on https may only call the bridge, not the AP itself.

              Firmware
                             
        
              
          How updates work
          
              New firmware for the AP, or for the tags over the radio. A tag image stays on the AP, and each tag of that model fetches it a part at a time at its normal polls (a few minutes at one poll a minute), keeps showing its price, and restarts into it. The arrow next to a tag in the table above updates that tag alone; the arrow next to a model below updates every tag of it, and the bars show how far they are. The AP restarts into its new firmware a second after the upload, and goes back to the old one by itself if the new one does not start or cannot be reached within three minutes. When this page has a newer release than the AP runs, an arrow-up button next to its version sends the image that fits it (with or without the status screen). New tag firmware should go to one tag of each model first, and to the rest once that tag has polled 10 times without problems: the table says how far each version is tried, and the page asks before it sends firmware to several tags of a model that no tag has run that long (it counts the polls it sees itself, in this browser, from the first time it sees a tag on the version). Tags flashed once with firmware that has the bootloader, and an AP flashed once over USB with it, are needed (tag-ota.md).

                  WiFi and API token over USB
                  
      
                  With the AP plugged into this computer, its WiFi and API token can be set from here, without its setup network. Chrome or Edge on a computer is needed (Web Serial). Close anything else that has the AP's port open first, such as esl_client.py ... serve: only one program can use it.
                  
      
                  This browser has no Web Serial. Use Chrome or Edge on a computer, or the AP's setup network (WiFi and API token).
                  
      
                  
        
        
      
                  
      
                  
        
        
        
        
        
        
        
        
                  
          
          
        
                  
      
                  
      
                  
      
                  Leave the network empty to change only the token, or the token empty to keep it. "Name" is the AP's name on the network: what your router lists, and http://NAME.local/. The token cannot be read back from the AP, so keep a copy. Opening the port can restart the AP; the page waits for it. From a terminal: esl_client.py --serial /dev/ttyACM0 wifi "Network" --password "..." --new-token "...".
                  
    
                  

    
                  
      
                  Getting an AP going
                  
      
                    
        
                  1. Flash it on the Flash AP tab. Its last step gives the AP your WiFi and an API token over the same cable. More: Flashing the AP.
                    2. 
        
                  2. No cable? An AP with no WiFi saved opens an open network openesl-XXXX. Join it from a phone and fill in the form that opens (or go to http://192.168.4.1/setup). More: WiFi and API token.
                    3. 
        
                  3. Keep a copy of the token. Every API request needs it, and the AP never shows it again. Lost it? Set a new one over USB above: no old token is needed. More: The API token.
                    4. 
        
                  4. Open it at http://openesl-xxxx.local/dashboard, or at the IP your router gave it. More: Dashboard.
                    5. 
        
                  5. Keep it running: send content, watch its health, update it and back it up.
                    6. 
      
                  
      
                  Stuck? See Troubleshooting. Developers: ap/README.md has menuconfig and how the AP stores things, and the API tab every call.
