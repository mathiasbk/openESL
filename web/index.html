Flash a tag with the ZBS_Flasher

      
Needs a D1 mini running atc1441's ZBS_Flasher, connected by USB, and Chrome or Edge on a computer (Web Serial). Each tag goes through the same steps as tools/flash-tui: the MAC is read, the whole flash is backed up in this browser before anything is erased, the MAC is written to the info page if needed, then the firmware is written and verified. The info page is never erased.

      
This browser has no Web Serial. Use Chrome or Edge on a computer.

Flash the access point (ESP32-C6)

      
Connect the ESP32-C6 board by USB and press the button. Chrome or Edge on a computer is needed (Web Serial). If the board is not found, hold BOOT while you plug it in.

      
Erasing the device also erases the AP's stored tags, layout files and settings.

      

      
        
        This browser cannot flash (no Web Serial). Use Chrome or Edge on a computer.
        Flashing needs a secure page (https).
